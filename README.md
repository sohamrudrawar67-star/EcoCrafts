# EcoCrafts — Artisanal DIY Lantern & Craft Kits 🏮🌿

EcoCrafts is a simple, sober, and mindful DIY craft e-commerce storefront. Designed with an earthy artisanal aesthetic, it enables customers to discover, customize, and buy handcrafted DIY lantern kits made from sustainable mulberry washi paper, natural bamboo frames, and warm ambient LED lights.

## ✨ Features

- **Artisanal & Sober Aesthetic**: Warm linen/cream palette (`#FAF7F2`), terracotta accents, washi tape ribbons, and delicate craft textures.
- **Evening Glow Mode**: Ambient lighting toggle simulating the warm lantern glow in a dimmed room.
- **Interactive Glow Studio**: Real-time room atmosphere simulator (*Daylight*, *Golden Sunset*, *Midnight Candlelight*) and paper finish preview (*Mulberry Washi*, *Terracotta Blossom*, *Pressed Fern*, *Star-Pierced Constellation*).
- **Curated DIY Kits Catalog**:
  - Nordic Fluted Paper Lantern Kit
  - Kyoto Hexagonal Washi Lantern (Kumiko bamboo lattice)
  - Botanical Pressed Flower Lantern Kit
  - Minimalist Geometric Origami Lantern
  - Celestial Star-Pierced Paper Lantern
  - Woven Rattan & Paper Lantern Duo
  - Petal Bloom Origami Lantern Trio
  - Solar Cyanotype Botanical Lantern
- **Full E-Commerce Experience**:
  - Slide-out Cart Drawer with dynamic quantity controls
  - Real-time Free Shipping Progress Meter ($50 threshold)
  - Quick Look Modal with kit contents checklist & specs
  - Checkout Modal with realistic order placement & receipt confirmation
- **Zero Extra Tools Needed**: All structural cardstock, bone folder, adhesive, cords, and flame-free micro-LED candles included in every box.
- **100% Standalone & Lightweight**: Pure HTML5, modern CSS3, vanilla JavaScript, and self-contained SVG artwork (zero external CDN or image hosting dependencies).

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or serve it locally:

```bash
# Python 3
python3 -m http.server 8000
```

Then visit:
```
http://localhost:8000
```
